# Transpiler Reference

The transpiler accepts three lists as input:
```python
phys_channels: list[str], 
virt_labels: list[str], 
virt_formulas: list[str]
```

If a remote system was configured to sample the following data in order:
 - Channel `T_amb` from location `cDAQ1Mod1/ai0`
 - Channel `T_surf` from location `cDAQ1Mod1/ai3`
 - Channel `T_fluid` from location `cDAQ1Mod1/ai2`

Then each call of DAQmx's Analog Read Nchan 1samp block would yield a 3-item double array, corresponding to the values [`T_amb`, `T_surf`, `T_fluid`]. As such, the transpiler should be given the list for `phys_channels` in the same order: [`T_amb`, `T_surf`, `T_fluid`].

If the user wanted the following virtual signals to be calculated per-sample:
 - Channel `T_mean = (T_amb + T_surf + T_fluid) / 3`
 - Channel `T_max = T_surf if T_surf >= T_fluid else T_fluid`

Then the list of virtual labels [`T_mean`, `T_max`] and virtual formulas [`(T_amb + T_surf + T_fluid) / 3`, `T_surf if T_surf >= T_fluid else T_fluid`] should match orders.

Passing those arguments into the transpiler, by calling:
```python
code, registers = generate_c_library(
    phys_channels = ["T_amb", "T_surf", "T_fluid"], 
    virt_labels = ["T_mean", "T_max"], 
    virt_formulas = ["(T_amb + T_surf + T_fluid) / 3",
        "T_surf if T_surf >= T_fluid else T_fluid"]
)
```

would return the following C code as a plain string in `code`:

```c
// Generated by main.py ({Path to transpiler}, {Timestamp})


void evaluate_channels (const double* __restrict__ phys, double* __restrict__ virt, double* __restrict__ trans) {

        // T_mean = (T_amb + T_surf + T_fluid) / 3
        virt[0] = (((phys[0] + phys[1]) + phys[2])) / (3.0);

        // T_max = T_surf if T_surf >= T_fluid else T_fluid
        virt[1] = ((phys[1] >= phys[2]) ? phys[1] : phys[2]);

}

// End of generated code
```

The generated code contains a double array re-assignment for each of the specified virtual channels. This necessitates that the array is reserved ahead of time. Each re-assignment has a comment with the original string, and an ERROR if the transpiler failed to evaluate the original string.

We can see some interesting outputs: Any division incurs a check for zeros, since we are not using safe division on the RT target. For the example above, `3.0` will never be equal to `0.0`, so the compiler will strip away the check and statically evaluate the `True` option. This is lazy on the transpiler's behalf, which should evaluate such expressions and exclude redundant checks. We can also see that Python's inline `if else` syntax is converted to inline `C` evaluations, allowing for more complex functions to be written.

The configuration code is available in [main.py](/src/main.py), and the output is in [main.c](/src/main.c). When compiled and run, main.c prints:
```
[80.50, 82.50]
```

Additional functions have been defined to provide additional abstraction and convenience. These functions relate to timing (`elapsed()`, `time_delta()`) and controls (`PID()`, `PIDa()`). When a called function has one or more dependencies, those dependencies are automatically added. Non-necessary dependencies are excluded to reduce output code/shared object size. To view the python-facing functions and usage, call `get_functions() -> list[str]`. Below is an example using some custom functions.

```python
code, registers = generate_c_library(
        phys_channels = ["ch_0", "ch_1", "ch_2"], 
        virt_labels = ["vch_0", "vch_1", "vch_2"], 
        virt_formulas = [
                "vch_2 + 3 / 4",
                "ch_0 + PID(ch_1, ch_2, 10, 1, 0.01)",
                "fmax(elapsed() - 1, 0)"
                ]
        )
```

Printing out `code` gives the following output:

```C
// Generated by main.py ({Path to transpiler}, {Timestamp})

#include <time.h>
#include <math.h>

// Generated dependencies

double PID(double pv, double sp, double gain_p, double gain_d, double gain_i, double* last_pv, double* acc_err) {

        // PID Controller
        // Uses pure gains (not times)

        double p_err = sp - pv;       // Proportional error
        double d_err = *last_pv - pv; // Derivative error
        *acc_err += p_err;            // Integral error
        *last_pv = pv;                // Proc var

        return gain_p * p_err + gain_d * d_err + gain_i * *acc_err;

}

double elapsed(double* start_s, double* start_ns) {

        // Elapsed time in seconds

        struct timespec now;
        clock_gettime(CLOCK_MONOTONIC, &now);

        if (*start_s == 0.0) {
        *start_s  = (double)now.tv_sec;
        *start_ns = (double)now.tv_nsec;
        return 0.0;
        }

        double total_elapsed = (now.tv_sec - *start_s) + (now.tv_nsec - *start_ns) * 1e-9;
        return total_elapsed;

}

// End generated dependencies

void evaluate_channels (const double* __restrict__ phys, double* __restrict__ virt, double* __restrict__ trans) {

        // vch_2 = fmax(elapsed() - 1, 0)
        virt[2] = fmax((elapsed(&trans[2], &trans[3]) - 1.0), 0.0);

        // vch_1 = ch_0 + PID(ch_1, ch_2, 10, 1, 0.01)
        virt[1] = (phys[0] + PID(phys[1], phys[2], 10.0, 1.0, 0.01, &trans[0], &trans[1]));

        // vch_0 = vch_2 + 2 / 3
        virt[0] = (virt[2] + 0.6666666666666666);

}

// End of generated code
```

Dependency functions are included where applicable, as are the header files required by those functions or implicit function calls like power `** -> pow`. There exists an additional safety check for division by zero; for the following python,

```python
code, registers = generate_c_library(
        phys_channels = ["ch_0", "ch_1"], 
        virt_labels = ["vch_0"], 
        virt_formulas = [
                "ch_0 / ch_1",
                ]
        )
```

This C is generated. The decision to provide a wrapper for the safe division was motivated by two points:
 1. Dividing by a stateful function would double-evaluate the function
 2. Transpiled code with inline checks become very messy very quickly

As such, one can observe (a) no `#include <math.h>`, (b) an ancillary `_safe_divide(x, y)` C function, and a clean call to `_safe_divide`. In this case, because no stateful functions are present, no registers are needed and `print(registers)` results in `0`.

```C
// Generated by main.py ({Path to transpiler}, {Timestamp})


// Generated dependencies

double _safe_divide(double x, double y) {

        // Zero-checked division

        return y != 0.0 ? x / y : 0.0;

}

// End generated dependencies

void evaluate_channels (const double* __restrict__ phys, double* __restrict__ virt, double* __restrict__ trans) {

        // vch_0 = ch_0 / ch_1
        virt[0] = _safe_divide(phys[0], phys[1]);

}

// End of generated code
```
